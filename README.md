# MySheets
MYSheets é uma aplicação voltada para o gerenciamento de fichas de personagens de RPG. Ela oferece um modelo de ficha, baseado no sistema que será usado, e permite ao usuário utilizar desse modelo para criar o seu personagem e então salvá-lo.

Suas funcionalidades são: Autenticação, cálculo automático de certos valores (Vida, Espaços de inventário, etc.), imagem de personagem (PNG/JPG), rolagem de dados, armazenamento, criação e edição das suas fichas.
